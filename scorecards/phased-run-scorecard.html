ICPI · Phased run scorecard

Run

One long run = one Run ID. Phases P1–P4 happen inside it without landing. All times in UTC (YYYY-MM-DD hh:mm:ss).

Scores

Score = Pass ÷ (Pass + Fail). N/A and open items are not counted; open items are shown so nothing looks finished when it isn't. Red and Blue are scored separately. Every Blue Fail is also a Red team win.

Red team · our drones

Fill in during and right after the run. "Did we fly what we planned, and is the data good?"

Blue team · Robin IRIS

Fill in later, when the IRIS data for this run has been received. Values come from IRIS data compared with our drone logs (domeware). Set the target before scoring, so Pass/Fail is not decided afterwards.

Rules

  • Pass: done as planned / the target was met. Fail: not done or target missed, write why. N/A: does not apply to this run, write why.
  • A phase set to Not used makes all its items N/A. Not used is neutral: it is not a failure.
  • Phases share one Run ID. Phase start/end must be inside the run and must not overlap.
  • Always a no-drone pause before and after each run, so IRIS data can be cut cleanly.
  • Approach (P3) is non-contact: the drones stop at the planned stand-off point. No payload, no contact.
  • Blue team values compare IRIS against our GPS logs on the same UTC clock. Write the source file for every value.
