Map areas you view while online are kept for offline use. To prepare a test site in advance, show it on the map and save it here.

DJI flight logs from format 13 on (DJI Fly, DJI Pilot 2) are encrypted. Orbit fetches the keys of each log from DJI once, then opens it offline. This needs a free DJI developer API key.

How to get a key
  1. Sign in at developer.dji.com.
  2. Choose Create App with the app type Open API, and fill in a name, category and description.
  3. Activate the app from the link DJI emails to you.
  4. Copy the key labelled SDK key from your developer page and paste it here.

Orbit Help

Data

Drone log
DJI flight records (DJIFlightRecord_*.txt), ArduPilot DataFlash (.bin) and telemetry (.tlog) logs, or CSV, GPX and KML tracks. Encrypted DJI logs need a DJI API key, set once under Settings › DJI; each log needs internet only the first time it opens.
Radar
Robin Radar IRIS XML, or any XML or CSV with track positions. For other formats Orbit asks which field is which.
Weather
Optional. Vaisala exports, or any CSV or xlsx with wind and temperature.
Fleet
Logs whose times overlap join the same scene, and the radar is compared with every drone.

Map

  • Drag to pan, scroll to zoom, right-drag or Ctrl-drag to rotate and tilt.
  • The drone path shows the radar status: magenta classified as a drone, cyan tracked, red not detected. Change it under Layers.
  • Click the path to go to that moment; click a radar track for its details.
  • Map areas viewed online stay available offline. To prepare a site, use Settings › Maps.

Results

  • The Analysis tab lists detection, classification, tracking and accuracy, and the CWA 18150 scores. Hover a value for its definition.
  • Export › Test Report (PDF) makes the report. Set its title, site and author under Test Details.

Definitions

  • Probability of detection: share of airborne seconds with a radar track on the drone.
  • Probability of classification: share in which that track was classified as a drone.
  • CEP50, CEP95: radius that holds 50 % or 95 % of the radar positions.

Live radar

  • Connects to the radar over TCP or UDP, or follows a file the radar software writes. Everything received is recorded for analysis afterwards.

CWA 18150 Scoring

Each metric scores 1 at its target or better and 0 at its worst value or beyond, linearly in between. CWA 18150 leaves these values to the end user, so agree them before the test. A weight sets how much a metric counts within its function; 0 leaves it out.
